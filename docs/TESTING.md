# 测试与验收

## 层次与目标

| 层次 | 操作 | 检查结果 |
|---|---|---|
| 静态与完整性 | 比较 source-sha256.json、检查 Cargo/Pixi 锁、脚本语法 | Rust 源码/资源完整，启动脚本无解析错误 |
| 单元测试 | scripts/build.ps1 -Test | spin 模块 19 个测试通过；不代表图像或弹道验证 |
| 本机运行 | 便携包、图形驱动、FastDDS XML | 可启动，收到连续且有限的 UDP 数值 |
| ROS 联调 | 实际订阅图像、CameraInfo、位姿并发安全控制命令 | 类型、QoS、单位、姿态变化符合预期 |
| 跨机算法 | 战队 Linux 自瞄 + 本仿真 | 检测/跟踪/预测/发射闭环及端到端延迟 |
| 新机复现 | 全新 Windows 克隆并安装/运行 | 排除本机已有工具或缓存的隐含依赖 |

做到哪一层、实际输出是什么，见 [证据说明](evidence/README.md)。没实测的层不算通过。

## 快速手工检查

1. 下载并校验 Release；使用入口启动，观察敌方位于前方、只旋转而非水平往返。
2. F3 切换自由/跟随/第三人称；F2 截图。WASD 移动、QE 旋转底盘、方向键操作云台、Space 手动发射。当前自动敌方运动会覆盖部分手动敌方控制，不能照搬上游最新多假人操作表。
3. 在监听机先执行 `python tools/udp_gt_capture.py 20 9870 logs/gt.jsonl`，再启动/保持仿真，确认目标地址指向监听机。
4. slow 7.5 场景运行 `python tools/verify_spin_gt.py logs/gt.jsonl 4 14`；triangle [-4,4] 场景最后两个参数使用 `-4 4`。
5. 改分辨率时实测图像宽高，并更新算法 YAML 内参和 ROI；45° 垂直 FOV 下 fx/fy 随高度缩放。
6. ROS 两端使用同一 domain 和消息定义。用 `image_rate_probe.py` 的 best_effort 订阅统计实际接收率，而不只看仿真窗口 FPS。

在 Windows PowerShell 中修改临时配置可设置 `$env:SPIN_MODE='triangle'` 等；如果 local.json 里也配置了同一键，local.json 会覆盖它。跨机实验先同步两端配置。

## 推荐实验矩阵

| 实验 | 固定项 | 唯一变量 | 建议记录 |
|---|---|---|---|
| 恒速基线 | 分辨率、距离、随机种子、算法版本 | SPIN_SLOW_OMEGA | 估计角速度误差、换板频率、命中率 |
| 变速/换向 | 距离与画质 | triangle 参数或 regular/irregular | 角速度/角加速度响应、跟踪重置 |
| 距离扫描 | 转速、算法与画质 | ENEMY_Z | PnP/距离误差、发射率与命中率 |
| 编码对照 | 相同场景与算法 | JPEG_QUALITY 或 IMAGE_PUB | 真实接收 Hz、延迟、带宽、send_err |
| 内倾对照 | 距离、转速与算法模型 | ARMOR_TILT_DEG 0/15 | 四角重投影、姿态偏差 |
| 开火门 A/B | 仿真配置不变 | 外部算法一项开火参数 | 近侧/总命中、发射数、预热时间 |

至少重复 3 轮，轮次交错 A/B，固定采集时长和暖机策略。不要把更少开火或更长预热带来的高比例直接解释为瞄准精度提升；同时报告每秒发射数和任务完成时间。

## 逐发日志与统计

创建 `logs/` 后，将 local.json 中 SHOT_LOG 设为 `logs/shots.jsonl`。每次实验使用新文件，源码以 append 方式写入。用 shot_id 关联 launch/hit/miss；手动发射可能没有最近 fire 请求，相应字段可能为 NaN。严格 JSON 读取器需容忍/转换这些非标准值。

统计原则：

- 总命中、近侧命中以每发首个/约定命中事件去重，并明确重复碰撞处理。
- 发射数包括手动和算法发射；孤立测试时避免混用。
- 停止开火后等待超过 2 s，给末尾弹丸完成命中/到期的机会。
- 记录有效控制比例、发射率、帧率、图像年龄，不能只报告近侧命中百分比。
- GT timestamp、shotlog 单调时间、自瞄遥测时间属于不同时间轴；校时、转换坐标和单位后再算到达时刻的板位误差。
- 历史 9871 自瞄遥测有交替数据流，分析时先按字段/类型分流，不能对相邻异构包直接求导。

## 解释限制

当前代理面 137.80×59.84 mm，与算法示例模型 135.7×56 mm 不同。near 是板面朝向判据，弹丸还会穿过某些车体几何继续飞行。当前仿真不等于真机试射，历史命中率不构成新机验收阈值。

当前发射代码使用直径 44.5 mm 的碰撞球和 44.5 g 质量，初速 25 m/s，线性阻尼 0.05。比 17 mm 真机小弹丸大这么多的碰撞体会影响命中判定；这里保持现状并记下来，没有为了指标好看去改物理参数。

`verify_spin_gt.py` 继承的“累积 int(omega)dt”用 ROS 系统时间，而运动积分用 Bevy Time。350 帧的短时三角波样本里这项不过，内部换向周期、过冲修正角积分、刚性板位都过。结果要逐项看，旧脚本的退出码不能当成整个仿真正确性的唯一判据。

数据集 writer 类存在，但 DatasetPlugin 当前只更新角点诊断，没有调用写出函数；若要训练集导出，应另立功能并测试可见性、标注顺序和写盘流程。
